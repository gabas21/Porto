# 💎 High-End Visual Design & Agency Standards

Pedoman dan aturan ketat untuk membuat antarmuka frontend terasa mahal, eksklusif, dan profesional (seperti buatan agensi ternama).

---

## 🚫 Larangan Desain Murah (Banned AI Patterns):
1. **Dilarang Warna Default Jenuh:** Hindari merah murni `#ff0000`, biru murni `#0000ff`, atau hijau murni `#00ff00`. Gunakan palet HSL tertata atau tinted dark backgrounds (`#090A0C`, `#0D0E12`).
2. **Dilarang Font Default:** Selalu gunakan tipografi modern berkarakter (misal: *Outfit, Inter, Space Grotesk, Syne, Geist Mono*).
3. **Dilarang Shadow Kasar Hitam Pekat:** Gunakan layered multi-step shadows dengan opacity lembut (`rgba(0,0,0,0.04)` + `rgba(0,0,0,0.08)`).
4. **Dilarang Card-Inside-Card Tanpa Alasan:** Gunakan pemisah garis tipis *subtle border* (`border-white/[0.08]` atau `border-black/[0.06]`) daripada menumpuk container tebal.

---

## ✨ Elemen yang Membuat Website Terlihat Mahal:
- **Perpetual Micro-Motion:** Interaksi halus pada hover, magnetic button, active state indicator.
- **Glassmorphism Berkualitas:** Menggunakan backdrop blur `12px - 20px` dipadukan dengan border 1px semi-transparan.
- **Hierarki Tipografi Ekstrem:** Kontras jelas antara display header besar dan subtitle monospaced berukuran 11px-12px dengan tracking renggang (*letter-spacing: 0.1em*).
