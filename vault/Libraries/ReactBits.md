# 🧩 Library: ReactBits UI

Kumpulan komponen animasi modern, modular, dan ringan berbasis React & Tailwind CSS untuk menciptakan visual website interaktif.

---

## 🌟 Komponen Kunci yang Sering Dipakai:

1. **`GlassSurface`:**
   - Efek kaca akrilik canggih dengan simulasi pembiasan cahaya (*distortion/refraction*).
   - Digunakan pada: Navbar pill saat scroll.

2. **`PixelSwap`:**
   - Efek transisi grid pixel interaktif saat hover atau klik.

3. **`AccordionGallery`:**
   - Galeri accordion horizontal yang meregang saat kartu disorot kursor.
